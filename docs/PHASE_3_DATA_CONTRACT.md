# Phase 3 to Phase 4 handoff

The machine-readable `outputs/phase3/phase4_input_contract.json` version is `phase3-to-phase4-v1`. It names the exact confidential local input path, SHA-256, 10,296-row grain `(account_id, reactivation_scenario, commercial_discount_tier)`, full schema, expected ranges, null policy, provenance fingerprints, 12-month time and currency conventions, and aggregate reconciliation rules. The financial assumptions fingerprint is `b953c02d3fdcfacc62d9e6755889040e9f8bd12db7c830a88c79f5c991267e70`; the frozen Phase 2 fingerprint is `6195ba2e90c95976ed91b7bdd42509341fd22e71e6b2bb5aed2e5d2a6d346ee7`.

The local-only file `outputs/phase3/local_only/account_economic_signals.csv` contains one account/scenario/offer row: account and root IDs, provisional cohort status, Phase 2 hazard and event probability, analytical expected present-value revenue and contribution components, activation PV, outreach allocation, expected account NPV, source-missingness and quality flags, explicit unconfirmed fiscal eligibility, and both model fingerprints. It is excluded from Git. The pipeline validates the file hash, exact grain and schema, numeric ranges, row-level financial bridge, and every cell's component and NPV sum against the portfolio oracle to $0.01. Aggregate files contain no account ID.

Before Phase 4 consumes the file, call `phase3_pipeline.validate_phase3_artifacts(repo_root, mode="handoff")`. The `complete` mode also requires and verifies the notebook and six figures. The validator checks every manifest entry present, current assumption and frozen Phase 2 identities, the account bridge, nine-cell portfolio sums, and a fresh independent account financial oracle. Manifest hashes prove consistency of the local files; they do **not** prove authenticity if an adversary can rewrite both an artifact and its manifest.

Phase 4 may read those local economic signals for planning, with a separately established routing policy that supplies review and blocked states. A positive account NPV is an **assumed economic signal**, not contact authorization or verified profitability. Provisional two-year inactivity is not confirmed fiscal-year eligibility. Unknown partner ownership is not direct-sales authorization, unknown health is not verified Green health, high assumed probability is not validated propensity, recorded historical spend is not ARR, synthetic Cox estimates are not customer evidence, and modeled program NPV is not causal campaign uplift. Phase 3 creates no route or contact action.
